Deutsch Quiz Studio

The Problem

A German language instructor needed an engaging classroom quiz tool that allows custom question creation while preventing students from clicking wrong answers in a playful way.

The Solution

Developed a quiz app featuring a dynamic "dodging" wrong button that flees from the cursor, an expanding correct button, automated German hint triggers, and a celebration confetti screen.

The Process

Designed a dynamic form, calculated real-time cursor distance for button dodging physics, implemented scale feedback, and applied a friendly "Just a Girl" color aesthetic.

Interactive Restaurant & Order Web App
ES6 Modules HTML5 Dialog Tailwind CSS

El-Bashawat Restaurant App

The Problem

Traditional restaurant sites suffer from slow page reloads during menu filtering, generic UI navigation that lacks brand identity, and clunky popups that degrade mobile performance.

The Solution

Engineered a custom knife-themed navbar, a high-performance native HTML5 dialog for video previews, instant multi-category menu filtering without page reloads, and a reactive cart system.

The Process

Architected clean ES6 modular code separating data management, DOM rendering, and cart logic. Built custom CSS knife UI shapes and utilized lightweight HTML5 modal dialogs.
